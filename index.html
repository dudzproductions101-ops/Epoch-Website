1. Introduction

Welcome to the official Epoch wiki! Epoch is an experimental x86_64 operating system project focused on building its own system from the ground up. This website covers topics such as:

- Installing and running Epoch

- Kernel and system development

- Built-in tools and applications

- Project history, contributors, and other information.

2. Installation

This section describes the general process for trying an Epoch ISO. Epoch is an experimental operating system, so installation steps and available features may change as development continues. Always check the notes included with the specific ISO you are using.

To get started, write the Epoch ISO to a spare USB flash drive using an image-writing utility. Connect the drive to the target PC, restart the machine, and open its BIOS/UEFI boot menu. The required key depends on the computer or motherboard manufacturer.

Select the USB drive as the boot device and continue. If the image supports your hardware, Epoch should begin its boot process.

Once the system starts, follow the instructions provided by the current build. Some components and installation steps may still be under development.

Before using Epoch on a primary machine, remember that development builds are experimental and may not provide the reliability or hardware support of a finished operating system.

3. Core Components

Epoch is being developed as an independent operating system, with its own kernel and core system components rather than simply acting as a preconfigured desktop distribution.

The project includes work on low-level system foundations such as booting, memory management, scheduling, filesystems, and communication between applications and the kernel.

Epoch also has a package format and package-management tools, alongside early userspace applications such as a file manager and Pong. These components are evolving as the system develops.

Compatibility and Applications

The project is working toward loading ELF applications and providing system calls that allow programs to interact with the operating system. Linux application compatibility is a longer-term goal and depends on implementing the required interfaces and supporting libraries.

Networking

Networking is part of the ongoing development effort. The goal is to provide the foundations needed for network interfaces and common network communication, with functionality expanding as drivers and network services are implemented and tested.

4. Development

Main Development Focus

Epoch's development is focused on building and improving the operating system's own foundations. This includes kernel functionality, hardware support, memory and process management, filesystems, system calls, executable loading, and networking.

Alongside the core system, development is also focused on creating a useful userspace: desktop and graphical features, command-line tools, built-in applications, and a package ecosystem that makes it easier to install and manage software.

Development Goals

  • Continue developing the kernel, boot process, memory management, and scheduler.
  • Improve filesystem support, system calls, and ELF application loading.
  • Expand hardware and networking support.
  • Develop the desktop interface and essential built-in applications.
  • Improve the VPK package format and tools for installing, removing, and managing software.
  • Work toward broader Linux application compatibility over time.

5. History

Epoch is the continuation of the operating-system development work that began with earlier project experiments. The project has changed direction over time, moving from assembling an existing Linux-based system toward developing a more independent operating system.

The Project's Direction

Earlier versions explored a minimal Gentoo-based system and configurable system components. As the project evolved, its focus shifted toward creating a custom x86_64 operating system with its own kernel and low-level components.

How the Project Is Evolving

Development has covered several areas, including booting, filesystem and virtual filesystem work, scheduling, userspace, package management, and graphical applications. More recent work has added features such as a file manager, Pong, an ELF loader, system calls, and networking support, with their completeness continuing to depend on testing and further development.

Epoch remains an experimental project. Its architecture, features, and development priorities may continue to change as new components are built and tested.

Epoch draws inspiration from operating-system development projects and systems that emphasize control, simplicity, modularity, and careful engineering. Its goal is to develop its own foundations while learning from existing operating systems.
